# 隔离球员密码流程专项验收

## 授权与环境

用户明确同意仅对隔离演练虚构球员临时改密、验证后恢复原密码，并允许本机临时保存恢复所需信息。此前被拒绝的操作没有执行；本轮取得授权后才执行。

操作前核对小程序服务为回环 61146、原演练 manifest 标记 fictional=true、原 demo.sqlite 路径及当前林远虚构球员身份。未操作真实账号或生产数据。受限临时恢复材料权限为 0600；文档、截图和结果不包含密码或会话令牌。

## 实际流程与结果

使用已安装官方 CLI 的真实元素 `input`、`tap` 和正常页面导航完成；未以页面方法调用、数据注入或直接 API 修改密码代替 UI 流程。

| 步骤 | 结果 |
| --- | --- |
| “我的”展开修改密码，输入当前密码和临时密码，点击保存 | 成功进入登录页 |
| 检查变更前独立旧会话 | `/api/auth/me` 返回 401，旧会话撤销 |
| 登录页输入临时密码并点击登录 | 成功进入球员首页 |
| 再次进入“我的”，输入临时密码和原演练密码，点击保存 | 成功进入登录页，原密码已恢复 |
| 登录页使用原演练密码并点击登录 | 成功进入球员首页 |
| 收尾核对 | 当前路由为首页，截图实际显示球员端；临时恢复材料已删除 |

正常恢复全部由真实 UI 完成，没有执行应急 API 改密。辅助 API 仅用于演练身份核对、旧会话撤销验证、恢复后原密码确认及注销辅助会话。

## 测试辅助脚本异常与处理

恢复原密码并完成原密码 UI 登录后，辅助会话注销接口返回成功空响应；测试脚本错误地按 JSON 解析空响应，导致收尾删除语句未执行。这是辅助脚本解析异常，不是应用改密失败。随后单独核对本次唯一恢复材料的范围与 0600 权限并删除，确认不存在遗留恢复文件。没有因此再次修改密码，也没有把脚本异常隐藏为全程无异常。
