# 球员照片集接口（第一批：独立上传）

头像与照片集独立，任何照片集操作均不修改头像。比赛相册来源关联、AI生成和微信邀请不属于本批。

## 权限与格式

现有有效球队成员可读取同队在队球员照片；归档目标不向普通球员展示。管理员可查看、整理或删除同队归档球员照片。所有写入仅管理员，读取与写入均鉴权，跨队返回未找到。不得将资源ID作为公开访问凭证。

最多9张。上传仅静态PNG/JPEG，原文件最多2 MiB，单边最多8192像素、总像素最多3200万。使用sharp实际完整解码；拒绝格式伪装、截断和多页图片；PNG按合法块边界显式拒绝acTL动画标记，不仅依赖解码器页数。按方向信息调整后以白底消除透明区域，再从raw像素重新编码JPEG，不携带EXIF/ICC等原元数据；输出也不得超过2 MiB。并发解码最多2个，繁忙返回429；sharp处理阶段配置15秒超时，不使用仅停止等待而让后台继续的Promise.race。不是无损格式保存，不承诺保留透明背景或动画。

原上传二进制不保存，数据库仅存处理后图片。删除清空内容、原始说明、当前说明和原图摘要，仅保留请求墓碑及基础技术元数据防止重复上传任务复活；不声称SQLite底层历史页或既有备份已物理抹除。退出后的客户端缓存管理由前端负责。

## 契约

路径前缀：`/api/players/:playerId/photos`。

| 方法与后缀 | 内容 |
| --- | --- |
| `GET` | `{player, revision, coverPhotoId, photos}`，列表仅元数据。 |
| `GET /:photoId` | `{dataUrl}`，鉴权响应禁止缓存。 |
| `POST` | `{revision,requestId,dataUrl,caption}`，成功201返回完整元数据列表。 |
| `PUT /:photoId` | `{revision,caption}`，修改说明。 |
| `PUT /cover` | `{revision,photoId}`，可设为已有照片或null。 |
| `PUT /order` | `{revision,photoIds}`，必须是全部现存照片ID的完整无重复排列。 |
| `DELETE /:photoId` | `{revision}`，删除并返回最新列表。 |

`player`仅包含服务端目标球员的`id,name,number,status`，用于确认正在管理谁，不含头像/备注。

照片元数据：`id, caption, mimeType, byteSize, width, height, createdAt, sortOrder`。说明最多200字符。

`revision`是独立相册版本，初始1，与球员资料revision不同。修改版本过期返回409。首张自动作为封面；删除当前封面时按现有排序回退首张，无照片则null。

`requestId`为16–100位字母、数字或连字符，推荐UUID。上传同任务原图及原说明相同，允许旧revision重查已有结果；不同载荷或已删除任务返回409，不复活照片。客户端遇到未知结果保留原任务和照片，先核对/重试同任务，不直接新建重复任务。修改、排序和删除遇到未知结果先重新载入核对。

完整解码异步完成后重新验证原请求会话，再在同步事务中复核账号与版本；退出、密码重置或归档导致会话失效时不写入。每次写入事务化，原版本不匹配不覆盖并发修改。

## 部署

官方npm依赖sharp锁定在`app/package.json`及锁文件；服务端通过以该package为根的createRequire解析，不能依赖从server目录裸import自动找到app依赖。根Dockerfile和app/Dockerfile均增加生产依赖阶段，将app生产node_modules带入运行镜像。

本地Mac已运行真实解码与重新编码测试；本轮production-deps阶段已在本地Docker的Node24 Alpine环境构建成功，生产运行时完整镜像与实际解码仍需分别验证，不将依赖阶段通过等同正式部署成功。应保留npm可选平台依赖，不用omit=optional去除sharp对应平台二进制。

安装时npm报告依赖树存在11条告警（2低、9中），独立审阅生产依赖audit为0，告警集中于既有开发工具链；未执行破坏性audit fix，不将完整依赖树宣称无风险。

## 测试与未验证项

专用12项测试使用合成图与临时SQLite，额外断言透明图重编码后像素为白色、合法CRC构造双帧APNG拒绝、超字节/单边/声明总像素限制、第三并发429及成功/失败后容量释放；覆盖完整解码、EXIF剥离、伪装/截断拒绝、排序/说明/封面/删除、独立头像、重新打开持久化、重复请求、跨队及球员越权、归档请求者与目标、异步后重新认证、CAS并发、九张限额、真实HTTP路由及DELETE请求体。尚不代表真机选图/预览/保存、Docker部署或任意恶意图片均已验证。

本批没有处理真实个人图片、访问生产数据、调用AI提供方或发布小程序。
