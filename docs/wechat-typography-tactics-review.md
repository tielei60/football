# 战术六页文字层级：已实施与实际复核边界

## 范围与取舍

基于项目内《微信小程序文字层级方案》及项目研究目录中标注为“大志有球”的参考材料（未独立核实是否为用户当前所指版本），只借鉴主要名称、数值、次信息的层级关系，不复制第三方素材或改变现有紫色主题。实际读取六页模板、样式以及三页画布的矩形测量逻辑后实施本批。没有改动 JavaScript、接口、权限、Canvas 绘制或触摸坐标。

| 页面 | 本批文字调整 |
| --- | --- |
| tactics | 战术名称30rpx/600，人数与阵型26rpx，来源24rpx/500，查看25rpx/500，说明24rpx。 |
| tactic-board | 仅普通展开态：标题650字重、制式26rpx、来源与提示24rpx、目标28rpx/600；专注与编辑态不追加文字覆盖。 |
| tactic-compose | 仅普通展开或球员属性态：字段标签26rpx、普通提示24rpx、作用范围说明25rpx/500深色；输入已有字号及继承字重保留。 |
| tactic-transfer | 分区30rpx/600、文件名26rpx、数量28rpx/500、风险26rpx/500警示色、普通说明25rpx。 |

| tactic-export | 标题650字重、来源与能力说明25rpx、已生成提示26rpx/500深色。 |

计划中的播放秒数字号增大、工具条按钮和选择值增大本轮暂缓。画布按实际起点计算剩余高度，即便不直接改 Canvas，工具条换行或抬高仍会缩小球场。因此专注工具条的字号、字重、行高、间距及选择文字省略方式均保持原样。表单标签不加继承字重，避免间接改变其内部原生输入文本。

只在普通流的指定辅助文字增加12px小屏下限，24rpx对应375px、25rpx对应360px、26rpx对应346px。未使用 `max()`，不涉及专注工具或播放时间。

## 严格保护与静态证据

- 原有六页 WXSS 前缀逐字保留，新增声明仅文字属性。
- 六页 JavaScript 的摘要与修改前一致；模板除class外逐字一致，所有 Canvas 节点、条件、事件和绑定未改变。
- 三个画布页新增文字规则全部限定普通展开态，不覆盖专注态。
- 不改 input/textarea 的字号、高度、padding、line-height、box-sizing；不改按钮、选择框、slider、网格、地图或预览尺寸。
- 独立 `tactic-typography.test.cjs` 四项通过；这不代表真实计算样式、键盘、画布矩形或视觉已验收。

## 背景与颜色边界

沿用现有主题变量。新增软紫文件名块使用 `--ink`，风险说明位于白色卡片使用 `--danger`；普通说明在白卡或页面背景使用 `--muted`。作用范围与跨制式说明使用深色 `--ink`。

父审阅提供的颜色计算表明，`--muted` 在白底约5.36、页面背景约4.90，但在软紫底约4.45，不能据此宣称所有现有文字背景均符合4.5要求。本批不向软紫属性面板添加灰色提示；专注态原有样式不变。新增文字仍须结合最终实际背景复核，不将主题变量名当作对比度证明。

## 未关闭的画布现象与受控复测

compose 展开态首次出现与此前相似的原生画布合成异常：真实开发者工具窗口也空白，但 buffer 采样100%有像素，画布矩形正常。不能只归咎截图，也不能据此证明由新文字样式造成。

随后受控使用旧、新两版，各进行3轮展开/专注检查，共12张图；刷新后均显示正常。试验结束文件已按SHA核验恢复。这只能说明该批受控复测未再次出现异常，不能宣称问题已修复、根因确定或归因于文字。保留该缺口继续跟踪。
