# 微信小程序球员身份验收清单

## 范围与记录规则

使用服务端认证的真实 `player` 角色及绑定球员的虚构演练账号，不通过客户端角色开关冒充权限。只使用隔离测试数据；不在文档记录密码、令牌或个人敏感信息。

本表为本轮修正后的最终验收清单。**待测不等于失败，也不因已有单测或此前 UI 检查而自动标通过。** 实测结果由实际操作人员逐项补充，分别记录真实操作、受控异常注入和静态审查。

## 本轮已实现的修正

- 统计榜单向球员详情传递合法 year 或 seasonId；详情使用后端 filter.label，不将无效赛季静默改查当前年。增加显式年度恢复入口。
- 比赛报名回调增加 owner、attempt、epoch、隐藏/卸载保护；同一进程内按 token + 比赛的共享在途互斥，成功或未知结果先读取核对再允许新写入，跨页面实例不重复提交。已知 4xx 可恢复；这不是多设备 CAS。球员详情隐藏时也使旧加载失效。
- 球员相册失败重试及本人密码/退出的会话生命周期由同轮对应改动处理；是否符合真实体验以最终实测记录为准。

## 最终实测批次记录

本轮实际操作使用微信开发者工具与隔离演练服务，记录来自实际操作人员逐批反馈：

- 自然故障：服务停机时首页网络失败，服务恢复后真实点击重新加载恢复，不是注入故障。
- 受控故障：仅相册一个请求一次触发失败，显示失败/重试并恢复；请求包装已撤除，无残留。该结果不代表真实弱网全覆盖。
- 比赛 6 原有效照片为 id 1、封面 id 1；id 2 为此前已删除记录。为双图预览临时增加 id 3，完成左右滑动与关闭及失败重试后已删除，恢复有效照片 1 张、封面 id 1。
- 比赛 3 报名恢复参加，SQLite 只读核验本人比赛 1/3/6 均为原 yes 基线。未提交战术模型或表单草稿，最终回首页。
- 密码实际变更/撤销因审批阻止未执行。慢网报名跨页逆序、跨账号迟回包、失效赛季主页面年度恢复按钮仅有自动检查，不能标为 UI 通过。
- 手机软键盘、中文 IME 候选、真机地图导航仍未验证。全页面逐元素的新优化计划属于后续待执行内容，不因本清单而宣称已完成。
