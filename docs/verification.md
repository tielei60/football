## 边界与数据保护

- 本地 Chromium 创建socket受限，云浏览器不能连接隔离执行主机；真实浏览器和容器验证在 GitHub Actions 完成。静态截图复核不等于逐步人工操作所有业务，也不代表Safari/Firefox或真实手机已验。
- 浏览器仅使用单worker和带所有权标记的临时SQLite；路径、标记、符号链接及清理顺序均有回归。新增赛季名单和快照也纳入隔离清理。服务端实验均使用独立临时库。
- 未替换真实业务SQLite、未合并main、未部署用户生产服务器。生产前仍需按[部署与备份](deployment.md)初始化管理员、配置HTTPS、持久化与一致性备份。
- 旧历史无法凭当前资料恢复原本未记录的赛时内容，迁移来源明确标注；旧比赛不猜赛季归属。当前仅单队界面；小程序/微信认证、完整多租户、财务、费用、训练签到不在本期。
