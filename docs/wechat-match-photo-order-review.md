# 比赛相册排序增量检查

## 实现范围

管理员在每张比赛照片下使用独立一行的“上移 / 下移”，首张不能上移、末张不能下移。封面及移除按钮保持原有一行，不将四个动作挤成一排。普通球员只读，不出现排序按钮。

请求为 `PUT /matches/:id/photos/order`，提交比赛 `revision` 与完整现存照片 ID 顺序。采用服务端实际返回顺序重新读取，不在响应前修改列表，也不因排序改变封面。后端版本、角色与球队隔离由接口负责；前端不将按钮隐藏当作授权机制。

排序沿用原有同账号、可见页与操作代次门禁。409 保留当前草稿并要求重新载入；网络或 5xx 的结果不确定时禁止继续排序，提示核对，不自动重试。未保存须知、待上传预览和说明沿用已有刷新保留逻辑。

## 自动化证据

本次新增 7 项匿名页面逻辑测试：完整 ID 置换与版本、首尾/非法方向/普通球员/隐藏/未知上传、重复点击与隐藏预检、409/网络/5xx、跨账号迟到错误。与既有相册和文字结构保护测试联合 37 项通过。

文字结构基线只排除本次精确新增的排序按钮区域与专属样式，旧区域保护保留。该结果不是微信真实触控、截图或服务端集成验收。
