# 比赛四页文字层级审查

## 范围与来源
本批依据 `wechat-typography-plan.md`，只修改 match-detail、match-edit、match-roster、match-media 的局部 WXSS 与必要语义 class。参考来源是此前实际查看的项目研究截图，项目标注为“大志有球”；未独立核实其是否为用户当前所指版本。不复制参考产品素材、橙色、布局或功能。

保持紫色主题、节点结构、角色条件、绑定值、事件、业务 JS、输入/textarea/按钮/picker 几何、地图与照片尺寸。原有样式前缀保持原文，本批仅添加一组明确命名的内容文字规则；未修改全局 app.wxss、其他页面或 Canvas。

## 具体落点
| 页面 | 选择器与层级 |
|---|---|
| match-detail | 双方 `.teams>view` 保持30rpx，字重600；比分40rpx/650。日期信息卡补 `.match-facts`，其标签25rpx muted、值28rpx/500 ink，避免误伤报名及战术留档行。名单补 `.roster-name`29/600、`.roster-stats`28/500、`.roster-meta`25。小节28/600，须知与复盘 `.prewrap`28/1.7。球场标题29/600、地址26、导航辅助23→25；不改地图。报名单位25并使用brand-ink（避免muted在brand-soft上静态对比不足）、数字字重650；固定栏标题27/600、当前状态25，保留固定栏padding、按钮及底部占位。 |
| match-edit | 标题34/650，字段标签24→26/500，小节28/600；草稿及计分说明25/1.6，错误26/500保留danger。不修改输入/复盘textarea、日期时间picker或清除按钮字体及尺寸。 |
| match-roster | 标题34/650、对手26/500，姓名29/600；标签23→26/500，说明23→25/1.65。顶部完整名单替换警告增加 `.roster-warning`，ink/500；历史说明保持muted。两列、选人、移除、进球助攻输入及所有下拉不变。 |
| match-media | 小节28/600；仅球员只读须知 `.prewrap`28/1.7，不覆盖管理员 `.notice` textarea。照片说明 `.photo-caption`27/500，封面24/500；上传限制25/1.6；未知上传结果 `.upload-uncertain`25/500 ink。错误26/500保留danger，照片与操作区域几何不变。 |

小屏通过局部媒体规则令24/25/26/27/28rpx内容文字在375/360/346/333/321px以下改为12px。只作用于列出的文字，不修改原生输入、按钮或picker。宽屏仍使用rpx；阈值整数取保守下界，不使用CSS max()。

## 保留的语义与独立候选
本轮不修改“未确定”、未知比分、报名与实际出场、首发/替补语义。此前提出 selectionStatus unknown 可改显示“首发/替补未定”，须另行授权、测试与长标签验收，不混入本次文字样式。

## 静态保护与验证边界
`match-typography.test.cjs` 与精简 baseline 检查四页去除class后的模板摘要、原有完整样式前缀摘要、新规则仅字体/字重/行高/颜色属性、无控件/地图选择器，并检查管理员/球员须知分支、地图弹层隐藏和现有未知文案保留。

这些是源码回归保护，不是实际computed style、点击域或输入光标验证。测试与模板最终结果在交付报告记录。本批未写入业务数据；实际视觉验证与待测边界见下文。
