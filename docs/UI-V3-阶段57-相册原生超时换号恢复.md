2026-11-19，用户 Mac 已解锁。复用专用微信开发者工具窗口及既有本机地址，不改变安全配置。产品代码未修改。

## 实际操作与结果

1. 管理员 A 通过界面登录，进入匿名甲相册，真实打开系统文件选择器，选择本机 64×64 纯色 PNG，看到预览后上传。未使用真实照片或微信凭据。
2. 本机隔离代理正常转发上传，后端返回 201 且 SQLite 已有一张照片，再暂缓回执。客户端约 15 秒超时，显示网络失败和结果待核对，而非假定失败后自动重传。
3. 使用返回按钮确认离开，再经“我的”退出并登录匿名球员 B。B 查看相册仅有一张照片，无管理员上传、编辑及恢复操作；“我的”显示匿名乙及对应球员信息，没有继承 A 的球员绑定。
4. 释放暂缓回执时连接已断开。重新登录 A，相册仍显示一张照片及“上次上传结果待核对”，选择照片、上传及编辑暂不可用。
5. 人工核对已有照片后点击“已核对照片列表”，阅读确认弹框并确认。提示解除，选择照片及可用编辑操作恢复，没有自动重传。
6. 代理最终统计上传 POST 仅一次；SQLite 球员照片总数为 1。未发生重复写入。

## 覆盖边界

本批原生验证的是“写入成功但客户端超时 → 正常换号 → 原账号重登 → 核对解除”。串行原生操作在换号前已经超过客户端 15 秒超时；释放时连接已断，因此**没有验证成功回调在换号后迟到进入原生客户端**，也没有验证进程重启恢复。不能把现有 HTTP/SQLite 集成测试的迟到回调覆盖算成本批原生通过。

阶段56的锁屏/选图阻碍本轮已解除，保留历史记录。没有因测试方便修改超时、安全设置、平台行为或业务规则，没有绕过确认操作。
