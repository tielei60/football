# 球员姓名占位头像：审查与验收记录

## 目标与边界

本轮在球员列表、管理列表、球员详情、我的及球员编辑页统一姓名占位头像，沿用既有紫色主题。姓名标识仅为缺少可用头像时的界面回退，不是照片，不表示已经匹配真人身份，也不生成或替换真实人像。

原有真实图片仍需保留；字段保存协议、权限及数据身份映射不得因展示优化而变化。原始资料初始化目前仅只读盘点，本文不宣称真实名单或照片已导入。

## 独立审查结果

已只读核对本批 13 个源码及测试文件，另附本文。共享首字工具去除首尾空白及列明的控制/不可见字符，按 Unicode 码点取首字，保留扩展汉字；空名、非字符串及孤立代理项回退为“球”。它不修改原姓名，也不做身份识别。码点处理不等于所有组合字形或表情序列完整分段，不作该项保证。

五页原有图片分支、aspectFill 及图片错误处理保持；只有没有可用图片时应用姓名占位样式。未改队徽、真实图片地址、头像容器尺寸或上传流程。错误回退仅清展示头像，不由本批向服务端提交删除。

球员编辑页的 initial 位于页面 data，而不在 form；姓名输入仍调用原字段白名单处理。save 从 form 构造原 payload，派生 initial 不进入请求。avatar 仍仅在原有图片操作产生私有 `_imageData` 时按原规则传入；不能笼统说所有保存都不含 avatar。没有新增后端、身份、账号或权限变更。

三个既有测试只作精准适配：管理文字基线把新增占位子树还原后再校验旧摘要，另外两处匿名 VM 加载器支持新首字依赖，原断言保留。新增 4 项匿名测试覆盖空名/扩展汉字/孤代理、既有图片及错误回退、管理输入与保存 payload、五页结构与样式约束。输入与保存检查为匿名 VM 调用配合依赖替身，不是实际 GUI 或 HTTP 保存。

本轮专项 4 项、全原生 660 项及官方模板 139 次渲染通过，diffcheck 通过。独立复跑相关 98 项、Web 构建、类型检查及 diffcheck 均通过；上述仍不是五页真实 GUI 验收。

## 实际验收范围

本轮尚未进行上述五页的实际 GUI 或真机操作；静态审查、模板及匿名测试即使通过，也不替代视觉、点击或读屏验收。不读取真实照片作身份猜测，不改写真实资料或上传个人图片。
