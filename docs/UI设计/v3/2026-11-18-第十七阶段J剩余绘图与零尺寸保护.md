## 零尺寸异常：失败与修复复验

1. 修复前真实选择椭圆，单击球场不拖动。模型新增一条起终点相同的椭圆，撤销变为可用；该不可见标注不应进入草稿。
2. 取消编辑，没有保存异常；只读检查除会话/登录审计外所有业务表与初始基线一致。
3. 同匿名库同步已审最小 `touchEnd` 修复、重新编译后，再次真实单击椭圆。页面提示“请拖动绘制有效标注，已忽略零尺寸。”完整 board 与基线一致，`canUndo=false`。
4. 随后有效椭圆拖动和水平直线均成功，避免为了拦截零尺寸而误拦合法单轴线条。

修复在代码层还覆盖直线/箭头起终点相同、矩形/椭圆任一轴为零。此次**原生单点复验仅椭圆**；其他零尺寸组合的通过依据仍是单测，不扩写成全部原生操作。
