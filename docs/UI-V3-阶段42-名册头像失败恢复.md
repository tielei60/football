# 阶段42：名册与球员管理头像失败恢复

## 设计依据与范围

依据《微信小程序 UI 全面优化-V3.md》03球队名册关于缺头像、图片失败占位、筛选组合可用的要求，审查球队名册及管理端球员列表。保持圆形头像、姓名首字占位、号码、位置、生成来源标签和原布局、配色不变，不增加静态演示头像。

## 已复现的问题

1. 共享加载器将数据序列化后传入页面，`players` 与 `visible` 是独立对象。旧逻辑只清除展示列表中的失败头像，筛选清除后又从底表恢复坏URL。
2. 错误事件仅按数组索引定位。筛选或排序后，旧图片错误事件会误清当前占据同一索引的其他球员头像。此时序通过控制器重放复现，未声称在微信设备上已观察。

## 修复

两页错误事件附带球员ID、图片URL、加载代次。共享处理器检查页面状态、当前账号和代次，再按ID与URL同时匹配底表及展示列表，只清理本地展示头像。不更改球员姓名、号码、位置、服务端头像或数据库。

筛选往返保持首字占位；主动刷新会重新读取URL，允许重试。刷新后旧代次、同球员旧URL、其他球员及已隐藏页面的事件不会清除新头像。

- 管理页面契约采用精确反向投影新增片段，原基线哈希及原断言保持；另测篡改、重复片段与额外代码。
