3. 选图只用本机新建纯色图；若开发工具文件选择或页面卸载使操作无法真实复现，记录实际阻碍，不用模拟成功回调冒充原生。
4. 测试后撤销两账号会话、停止两个自有服务；不写真实库、不更改安全设置。
