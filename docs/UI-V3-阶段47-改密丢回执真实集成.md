# UI V3 阶段47：改密成功丢回执的真实集成验证

## 复现与修复
V3“我的”和“首次修改密码”要求错误反馈正确。真实临时HTTP服务与SQLite配合生产小程序api.js、页面控制器：服务端已返回204，测试故意不把成功交给客户端，而返回网络失败或模拟502。旧会话、旧密码均已401，新密码可登录，但原界面显示普通“网络失败，请重试”，强制改密的未知结果兜底也被非空错误文本遮蔽。修前两页失败测试已复现。

两页只将无状态码/5xx改为“修改结果未确认，请退出后使用新密码登录核对；不要直接重复修改。”明确4xx仍显示原服务端拒绝。没有新增自动重试、强制退出、永久锁定或存储密码，没有修改认证规则及当前字段清理行为。该提示不保证修改已成功；请求未送达也属未知，需要用户核对。
