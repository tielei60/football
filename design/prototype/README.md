# TOUCHLINE / 边线：俱乐部 UI 基础原型

这是供确认视觉方向的独立原型，不是已接入业务的新版本。仅新增本目录，不修改现有应用、数据库、登录或接口；确认整体方向后再实施完整改版。

## 查看

下载并在浏览器中打开 `index.html`。单文件包含所有样式、图标及脚本，没有外部字体、图片、网络请求或安装依赖；队徽原始 PNG 以 data URL 内嵌。页面顶部始终标注“设计原型 · 比赛与球员为虚构数据”。刷新恢复初始示例。

## 设计方向

- 以项目原有柏林花园 FC 队徽为色源：葡萄紫约 `#650164`、冰蓝约 `#A2D9F7` 和白色。原队徽不重绘、不改色。
- 采用提亮的柔紫 `#8845A0` 作为主按钮、选中项与球队标记，冰蓝小面积点缀；避免整片深紫侧栏、主卡和画布。
- 大面积白色、极浅薰衣草 `#FAF8FC` 底色，配深紫灰 `#2F2636` 正文；日常表单、列表和记录保持明亮、清楚。
- 编辑式标题、大比分、细边框、克制圆角与留白，不沿用默认组件主题。
- 统一自定义赛季/阵型下拉，包含展开、选中、焦点及键盘操作。

## 代表页面与可试操作

1. **工作台**：新入口布局提案。下一场比赛、报名三态和未回复、最近比赛、数据覆盖与名单/战术入口。
2. **比赛日程**：筛选与自定义赛季下拉、列表/详情双栏、报名/名单/战术/复盘标签、新建比赛弹窗及独立保存动作。
3. **战术室**：七人制球场、人员/号码、工具栏、自定义阵型下拉、两步跑位动画和首发名单。
4. 顶部切换管理/球员预览。球员不能新建、保存或改阵型；可以表达报名意愿与播放演示。报名和实际出场仍分开。
5. 下拉可用方向键、Home/End、Enter、Escape；弹窗支持取消、Escape、Tab 焦点循环和关闭后恢复焦点。

## 数据和范围边界

- 队名与队徽使用项目已有的柏林花园 FC 品牌；球员、对手、比赛、日期和统计数字仍为虚构演示，不代表真实球队记录。新增比赛及报名只存在当前页面内存，不发送通知，不写入本地存储或任何数据库。
- 非首场比赛的名单/战术区域是固定设计示例，页面持续提示；不把它当作真实多场数据实现。
- 未知比分、覆盖场数、未回复、首发/替补/实际出场，以及模板/版本/比赛快照的区别保留。
- 图形工具仅演示选中态，不提供自由绘图。版本管理、导入导出、完整统计/球员管理等现有能力没有被替换，也尚未在此原型全部重做。
- 日期与时间在本原型中仍使用浏览器输入；完整自定义日期交互、手机细节和全站错误/加载状态留待方向确认后实施。
