# 微信邀请本机隔离演练

这是可复现的匿名管理界面演练，不是微信认证上线工具。不会读取生产数据库路径、管理员密码或微信配置，不自动改小程序配置，不发送邀请，不调用真实微信。

## 启动

使用 Node.js 22.13 及以上，先在 `app` 执行 `npm ci`，然后从仓库根目录运行：

```sh
node scripts/start-wechat-rehearsal.mjs disabled
# 或启用模拟邀请管理界面：
node scripts/start-wechat-rehearsal.mjs enabled
```

每次启动都生成新的私有临时目录、匿名 SQLite 库和随机密码，只监听 `127.0.0.1` 随机端口。不支持指定已有数据库、固定端口、AppSecret 或恢复旧库。不会继承生产来源、代理和管理员设置。

终端仅打印地址和私有清单路径，不打印密码或核对编号。目录权限为 0700，数据库及清单为 0600；清单中的管理员和球员账号仅供这次本机演练，不应上传或分享。

## 四种模拟前提

- 密码队员：可用清单内球员账号登录。
- 未邀请队员：管理员可实际创建和撤销邀请。
- 待审核队员：初始化阶段通过可信模拟适配器准备申请；清单 `prepared.claimed` 提供核对编号，可在界面审批或拒绝。
- 已绑定队员：初始化阶段通过模拟身份及正常审批接口准备绑定，可在界面解绑。

这些认领和绑定是 **API 模拟前置数据**，不是扫码实测。无论模式，运行服务器都拒绝所有微信凭据交换，不接受任何“测试万能 code”，也不会把真实微信 code 发送出去。启用模式只能验证邀请管理及关闭/错误提示，不能证明真实微信快捷登录成功。

## 小程序操作与收尾

如需界面验证，由操作者备份本地忽略文件 `miniprogram/config.js`，手工将 API 根地址设为终端打印的地址（不加 `/api`），仅本机调试允许本地 HTTP。脚本不会读取或修改该配置，也不会保存原登录令牌。

结束前正常退出演练账号，恢复原配置字节，再按 Ctrl+C 停止服务器。停止不会自动删除临时库，以便核查结果；确认不再需要后仅删除终端输出的本次演练目录。不要删除其他数据目录。恢复配置不代表恢复原账号登录，也不会启动原服务。

## 自动验证边界

专项：`node --test app/tests/wechat-rehearsal.test.mjs`。覆盖参数拒绝、全新私有目录、虚构生产环境值不被继承、默认关闭、真实密码 API 登录、启用模式任意交换拒绝以及独立实例关闭。测试不使用真实密钥或生产数据；不等同手机、真实微信登录或全界面验收。
