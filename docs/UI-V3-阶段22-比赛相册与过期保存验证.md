# UI V3 第二十二阶段：比赛相册与过期保存

## 范围与设计依据

本阶段在开发分支继续核对「须知与相册」与「安排比赛」。参照 V3 第 19 页原图及原型：750 像素原图中照片高度 376 像素，原型为 188 CSS 像素，因此照片区使用 376rpx。保留页面结构和业务功能，封面操作使用品牌描边层级，移除操作弱化为文字层级。

本阶段未使用正式数据库或真实照片。原生操作使用新建匿名演练库、纯几何 PNG、仅监听本机的服务；微信绑定与 AI 服务均关闭。

## 发现并修复

1. 比赛相册返回页面时，同一会话的角色变化未及时更新管理员操作。现在立即更新只读状态、废弃旧选择结果；若写入尚未结束，则结束后刷新。相同角色返回不清除草稿。
2. 排序请求已发出后隐藏再返回，未知结果可能被视图轮次守卫丢弃。现在由原操作所有者、请求轮次及尝试身份判定，恢复冲突提示，不自动重发。
3. 比赛编辑保存收到当前请求 401 后，会话已被清空，原有效性守卫导致等待状态未正常结束。现在仅当前页面、当前保存且非旧会话的 401 结束等待并走统一登录恢复；旧账号、隐藏页及卸载页不得接管。
4. 相册照片区由 420rpx 调整为设计要求的 376rpx，并统一封面/移除按钮层级。

## 自动检查与独立复查

- 小程序完整测试：**1040/1040 通过**。
- 新增比赛编辑 401 的当前页、旧账号、隐藏、卸载及旧会话回归。
- 新增比赛相册角色返回、操作中降权与排序未知结果回归。
- 原始行为 SHA 不变，只对已审查的唯一精确改动做逆投影；保留重复、篡改和额外改动的拒绝断言。
- 独立复查相关测试 **56/56 通过**，未发现阻断问题。
- 对照原图检查照片尺寸及操作层级，未将配色修改扩展成无关重构。

## 不应误读为已验证的范围

本轮没有完成真机图片权限、图片加载失败后重试、全部图片格式错误、容量入口的新增原生复验，也未新增实际照片上传记录。角色切换和未知排序恢复本轮由自动回归覆盖；之前阶段的上传、封面、排序、删除和容量记录仍保留其原覆盖边界。外部 AI、真实微信认证和真机表现继续待验。
