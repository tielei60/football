# 本机 AI 照片模拟演练

## 范围与启动

此工具让本地开发者用现有后端接口演练授权、样本准备、任务、私有候选和明确采用。它只生成紫色或白色几何测试图，不分析人像、不调用真实 AI、不产生费用。微信认证始终关闭，不能把这个工具当作微信或供应商接通证明。

仓库已安装依赖、Node.js 满足项目要求后，在仓库根目录运行：

```sh
node scripts/start-ai-rehearsal.mjs
```

不接受任何参数，也不接受数据库路径、端口、供应商或密钥。脚本使用随机空闲端口，仅监听 `127.0.0.1`。终端输出本机地址与私有清单路径，不显示密码。

每次运行会在系统临时目录新建 `football-ai-rehearsal-*` 目录：

- 目录权限0700；独占新建数据库及 `private-manifest.json` 权限0600。
- 仅4名虚构成年球员、一个随机密码管理员及一个虚构球员密码账号。
- 清单含本机演练账号及球员编号，供操作者在本机查看；不要上传、提交或将其贴到聊天、日志及截图。
- 无真实名单、照片、比赛、报名、微信身份或既有 AI 任务。
- 不读取生产数据库、管理员、微信配置，不修改小程序配置或已有服务。环境中的数据库路径、端口和供应商变量不会成为本工具的目标。

小程序需要测试时，由操作者明确选择这个本机地址，结束后恢复自己的原配置。脚本不自动替换配置，不提供生产部署方式，也不会让本机地址变成真机可访问服务。

## 建议演练顺序

1. 用本机清单中的管理员密码登录，选择虚构球员。
2. 检查界面标明本地模拟、零费用；仅选择几何样本，不选择真实个人照片。
3. 确认私有样本用途，创建样本；选择测试样式及头像或出场照用途，再明确确认生成。
4. 等待任务完成，查看私有候选。此时球员相册和头像应保持原样。
5. 明确选择采用到对应头像或相册/封面，核对保存结果与模拟来源标记；未确认不得自动采用。
6. 退出后用虚构球员密码账号登录，核对其不能进入管理员 AI 操作。不要把已采用图片的相册可见性混同私有候选访问权限。
7. 检查取消、重复点击和重新载入时，只以真实界面或接口结果判断，不以状态注入代替操作。

真实供应商、照片处理授权、费用限额、失败计费、正式密钥和真机验证均不由此工具解决。

## 停止与保留

按 `Ctrl+C` 或发送 `SIGTERM` 停止本次服务。关闭本次监听和连接后，等待服务的 `server.drained` 完成已跟踪任务与SQLite资源收尾；不强制 `process.exit`。强杀进程不具备同样的收尾保证，仍应核对任务状态。

正常停止保留本次临时目录，供本地核验；操作系统可能清理临时目录，因此它不是长期备份。启动失败只清理自己刚创建的目录，不删除已有演练或生产库。需要手工清理时，先停服务、核对确切目录，再移除本次目录，不使用通配符批量删除。

## 自动化证据与边界

```sh
node --test app/tests/ai-rehearsal.test.mjs
```

本批3项隔离测试通过：

- 拒绝任意参数及外部配置；新私有库、随机账号密码、环境哨兵文件不被修改。
- 微信关闭、管理员登录、球员 AI 权限拒绝；HTTP 走几何样本授权、任务、私有候选、采用前相册为空、明确采用后出现带模拟标记的封面。测试期间禁止 `fetch` 外呼，HTTP 只连接本机随机端口。
- 服务关闭可重复调用且端口停止；异步监听失败保留原故障并清理本次新目录。

仅使用虚构数据，测试结束清理自己生成的库。不等同原生界面逐页验收、真机测试、真实微信登录、真实 AI 图片生成或商业费用验证。测试由现有 `npm run test:unit` 通配入口自动收集。
