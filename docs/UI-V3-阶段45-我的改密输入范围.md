# UI V3 阶段45：我的页面改密输入范围

## 对照要求与发现
V3 第05页要求核对修改密码表单的输入、错误与成功后重登。实际页面的新密码输入允许256个字符，控制器仅检查至少10个字符；服务端 `server/club-store.mjs` 的既有 `hashPassword` 规则为10–200个字符。因此201–256字符可从页面提交，但必被服务端拒绝，页面提示未告知上限。

## 修改范围
- 新密码输入上限与提示统一为10–200个字符。
- 控制器同时验证上下限，越界时在本页提示且不发送请求。
- 不裁剪密码或首尾空格；不改变当前密码输入限制、认证接口、会话撤销与重登规则。
- 不改变页面结构、颜色和布局，不触碰数据库或用户本机文件。

## 检查
- 新增0、9、201、256长度拒绝，10和200边界允许，以及输入模板/后端契约检查。
- 24项改密及认证生命周期定向测试通过。独立只读复查的18项表单及界面契约测试通过。
- 原始源码哈希不重置，仅对本次校验片段做精确反向投影；原篡改、重复片段与生命周期保护保留。
