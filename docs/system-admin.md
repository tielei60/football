# 系统管理员与本机初始化

## 权限边界

现有 `admin` / `player` 角色保持兼容，系统管理员是普通管理能力之上的独立 `systemAdmin` 标记，不自动授予任何旧管理员。账号管理范围仅当前球队，不扩展到其他球队。

系统管理员可创建独立普通管理员、把已有球员账号授予普通管理员、将关联球员的普通管理员撤回球员，或停用普通账号。无关联球员的独立管理员只能停用，不能伪造球员关联。系统管理员行在账号管理接口只读，不能通过公开API创建、升级、停用或修改系统管理员。数据库另有最后一名启用系统管理员的删除、降级和停用保护。

普通管理员仍可管理业务，但无账号授权管理接口权限。每次授权修改在事务内重新核验操作者身份、修订号、球队和系统权限，再校验目标修订号；变更删除目标全部会话。停用账号不能密码登录、微信签发新会话或继续使用旧会话。已有合法微信绑定的关联球员授予普通管理员后仍可微信登录，但必须保持球员关联、在队、账号启用且非系统管理员；不新建绑定或绕过首次改密。授撤权限及启停账号同时推进微信交换代次，拒绝跨过变更的在途旧交换。

## 接口

- `GET /api/system/accounts`：当前球队账号数组。
- `POST /api/system/accounts`：仅接受 `username`、`password`，创建普通管理员，返回201。新账号必须首次改密。
- `PUT /api/system/accounts/:id`：接受必填 `revision` 与可选 `role`、`enabled`，返回更新结果。修订冲突409，越权403。
- 账号投影：`id`、`username`、`role`、`playerId`、`systemAdmin`、`enabled`、`revision`、`passwordEnabled`、`mustChangePassword`。不返回密码哈希。
- 会话用户新增 `systemAdmin`、`mustChangePassword`、`accountEnabled`、`accountRevision`，保留原字段。

创建接口不自动重试。响应丢失时应刷新列表核对账户名；“账号存在”不等于可以确认本次密码已设置，不能自动覆盖或重建。

## 首次改密

常规设置密码仍须10至200字符。必须改密的账号可以登录，但服务端只允许查看自己的会话、修改密码和退出，业务接口返回403及 `code=PASSWORD_CHANGE_REQUIRED`。公开健康检查、能力标记和静态页面不包含授权业务数据。

`PUT /api/auth/password` 要求当前密码和符合常规规则的新密码。成功后清除首次改密标记并撤销全部会话（包括当前会话），前端必须清缓存、重新登录。不能只用隐藏按钮代替服务端限制。

## 本机一次性初始化

先核对目标为本项目的 `app/data/football.sqlite`，停止使用该库的服务。若文件不存在，先按明确的数据范围准备干净本地库；脚本不隐式生成业务资料，也不接受任意路径。

```sh
node scripts/setup-local-system-admin.mjs
```

仅支持本机交互终端，无命令行参数，不读取环境变量密码，不接受管道凭据。输入账号名与不回显的临时密码。脚本先生成私有SQLite一致性恢复副本，再迁移并初始化；恢复副本含私有数据，不上传、不提交Git。密码只存随机盐scrypt哈希，不写入清单或输出。

只有此本机初始化允许6至200字符临时密码，且强制首次改密；不降低常规登录后设置密码规则，不将特定真实账号或密码写入源码、测试和文档。已有系统管理员或用户名冲突时直接停止，不重置或覆盖账户。旧普通管理员保留，不自动升级也不批量删除。

此入口不是远程生产部署或密码恢复接口。恢复副本需要在停服并核对路径、权限后由操作者显式恢复，不能自动覆盖仍在使用的数据。系统管理员的额外创建、重置与灾难恢复不通过普通管理API提供。

## 验证与限制

```sh
node --test app/tests/system-admin.test.mjs app/tests/setup-local-system-admin.test.mjs
```

匿名测试覆盖旧管理员兼容、仅本机初始短密码、首次改密门禁与会话撤销、强度规则、同队授权、跨队拒绝、CAS、失效操作者、停用、球员授撤管理权限、最后系统管理员保护、初始化冲突与回滚。真实账户初始化、真实首次改密及完整两端UI需要另外按授权范围实操，不能以匿名测试代替。凭据及含真实资料的恢复副本永不提交。

2026-11-15 后端验证：系统账号与本机初始化6项专项、后端及脚本合计260项匿名测试全部通过，0跳过。首次改密拒绝继续使用原初始密码；故障数据中关联球员的系统账号也不能从普通球员重置路径接管。另修复了两份柏林演练测试的临时目录快照相互干扰，改为精确追踪本测试创建的目录，保留失败清理断言。

以上不代表真实终端密码输入、实际本地系统账号初始化或两端界面已经验收。初始化脚本保留用户明确指定的本机目标，不在自动化测试中运行真实账号设置。既有普通管理员对关联普通管理员的球员密码重置规则本轮保持不变，系统管理员例外明确拒绝。
