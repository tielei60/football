# 第十七阶段 G：真实文件导入导出验证

## 范围与结论

2026-11-18，使用最新已审小程序代码、专属交互工程和新建匿名隔离数据库验证。当前微信开发者工具中的“选择 JSON 文件”实际打开 macOS 本地文件选择窗口。本批通过 CUA 在该窗口选择文件，没有向微信聊天发送文件，没有 mock 文件选择回调，也没有用 `callMethod`、`setData` 代替操作。

导入、导出临时文件及离页清理通过；系统另存受开发者工具限制，**不能称为完整系统保存或真机验证通过**。

## 真实操作覆盖

| 文件/操作 | 实际反馈与核验 |
| --- | --- |
| 损坏文件.json | 提示选择有效 JSON 战术备份 |
| 错误版本引用.json | 提示备份格式不支持或内容无效 |
| 超过历史上限.json | 明确提示单套超过 50 个历史版本，为避免丢失本次未导入 |

| 旧演示兼容.json | 同样实际预览与确认导入；保留末阶段旧演示曲线 |
| 离开重进战术列表 | 两项导入标题均可见，保留截图 |
| 重进导入导出页，点击生成临时 JSON | 实际生成文件，读取实际内容，与数据库完整集合一致 |
| 点击保存到本机 | 提示“开发者工具暂不支持系统另存”；没有声称保存至系统目录 |
| 离开导出页 | 对生成文件的原路径执行只读访问检查，返回不存在 |
