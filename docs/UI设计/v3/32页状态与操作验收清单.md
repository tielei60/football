## 已执行证据的边界

- 代码回归与官方模板渲染不代替原生操作。
- 匿名视觉夹具不运行真实控制器；其正常/加载/错误/空态截图只证明布局。
- 第二阶段使用真实控制器与临时数据库完成登录、30页加载、日期确认取消及保存、球员三态报名、身份拒绝、退出和数据库核对。不是全部操作覆盖。
- C/U/P需要隔离代理延迟/断响应或双会话冲突触发，不能只setData后称业务通过；重试前后必须核对无重复记录。
