# 相册文字与未知排序结果复核

## 本批范围

仅球员相册和比赛媒体页的已有业务，不新增接口、权限、阶段排序或照片处理服务，不改真实照片及数据库。

- 球员照片说明、比赛须知使用三方比较：刷新前服务器基线、本地文字、新服务器文字。
- 未编辑项跟随新服务器内容；真正未保存草稿保留。若服务器与草稿都变化且不同，明确提示冲突，保存前展示服务器文字和保留文字并确认替换。长文仅在确认框节选，编辑框保留完整草稿。
- 服务器内容已经等于草稿时消除冲突；重复刷新不静默消除未确认冲突。
- 确认捕获目标照片、文字、版本、账号和页面代次。取消不写；确认期间刷新、隐藏、换账号或目标删除均阻止旧保存。再次并发修改仍由服务器版本冲突拒绝。
- 球员相册排序遇到网络未知或 5xx 时锁定，要求重新载入核对，和比赛相册一致。确定 4xx 保持原规则；隐藏期间未知结果在返回时重新核对，同账号先返回后迟到的未知结果仍锁定。换账号迟到结果不污染新页面。
- 说明冲突不禁止无关排序或封面操作；未知写入仍要求整页核对。
