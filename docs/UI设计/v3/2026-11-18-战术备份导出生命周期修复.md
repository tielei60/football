# 战术备份导出生命周期修复

## 发现的问题

静态代码审查发现：管理员发起导出后，如果读取战术集合的响应迟到，此时页面已经隐藏或隐藏后重新显示，旧响应仍可能生成临时备份文件、覆盖当前提示。原实现只检查账号归属，未检查此次导出所属的页面显示轮次。

新增三个回归测试先复现失败：离页后生成旧文件、离页再返回仍生成旧文件、旧错误覆盖当前提示。

## 修复

- 为本次导出捕获显示轮次，在会话检查后、集合返回后以及错误提示更新前，同时检查账号归属、页面可见性、显示轮次。
- 失效响应不写临时文件，不覆盖当前提示；仍清理本次忙碌状态。
- 不修改导入收据、已有备份格式、权限、系统另存和文件清理逻辑。
- 不在隐藏时删除已有文件，避免系统另存窗口导致页面隐藏时误删正被使用的文件。

## 验证边界

- 导入导出专项：34/34 通过。
- 战术专项 `tactic-*.test.cjs`：141/141 通过。
- 新增案例为控制器生命周期自动化回归，不代表真实文件选择/系统保存或真机已验证。
- 未访问、导出或上传正式球队数据、照片及密钥。

独立只读代码复查通过；补充会话预检期间隐藏后返回的防派发测试，通过。
