# 阶段44：战术导出预览与另存反馈

## 设计依据

V3第25页要求生成、预览、保存三个阶段及文件预览失败、保存不支持状态清楚；仅本机处理，不自动分享或申请相册权限。此次只补错误反馈与迟到回执保护，WXML、WXSS和系统调用范围不变。

## 发现与修复

- PNG预览缺少失败回调，用户无法知道失败原因。
- PDF预览、另存失败回调只检查页面销毁；另存成功只检查账号。换账号或重新生成其他文件后，旧回调可覆盖新结果状态。
- 系统API同步抛错时没有可恢复反馈。

现在PNG/PDF预览及另存回调同时绑定所操作文件路径与账号；旧文件、旧账号和卸载后的反馈不更新页面。失败显示现有错误区域；取消不报失败，另存成功只在实际成功回调显示。重试清除旧错误，重新另存不沿用上次成功文案。

系统预览或另存可能临时隐藏页面，回调不以隐藏状态或页面代次作判据，避免误丢同一文件的正常系统回执。不代表撤销已交给系统的保存请求。

## 验证

新增5项控制器测试覆盖两种格式失败、取消、同步抛错、旧文件/旧账号/卸载回调、临时隐藏及正常保存；与原导出测试合计13项通过。独立代码复核完成。原七页业务基线通过精确反向投影保持，相关组合17项通过。
