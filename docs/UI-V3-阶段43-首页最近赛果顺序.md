# 阶段43：首页最近赛果顺序

## 设计要求

《微信小程序 UI 全面优化-V3.md》首页要求展示最近赛果，使用真实比分、日期及胜平负，不用示例数据。此次不调整卡片布局、颜色、下一场筛选或统计口径。

## 问题与修复

服务端比赛列表同日按ID倒序返回，旧首页只按日期排序再取前三场。补录同日较早比赛时会维持创建顺序，甚至把当天较晚比赛挤出最近三场。

使用实际首页控制器复现：同日按补录顺序返回08:00、10:00、12:00、20:00，旧输出前三项为08:00、10:00、12:00。现在先按比赛日期和开球时间倒序，再取前三场，输出20:00、12:00、10:00。

与赛程页现有排序规则保持一致：同日已知时间在前，空时间在后；相同时间维持原顺序。不改变服务端、正式数据和其他状态规则。

## 验证

- 新增4项实际控制器回归全部通过：同日补录、跨日期优先级、排除草稿/取消/未完赛、零与未知比分、无记录、空时间与相同时间。
- 独立代码复查通过；仅改首页最近赛果排序一行。
- 全量1333项中1306项通过、27项浏览器布局检查受云端socket权限限制；应用构建及140次官方模板虚拟渲染通过。Mac离线，不能声明原生视觉或点击验收。
