# UI V3 阶段46：战术列表空态语义

## 对照与范围
V3第20页要求分别测试当前模板、历史留档、无战术与搜索无匹配。原页面所有空态统一显示“暂无匹配的战术”，真实没有记录时也像搜索失败。

仅替换原空态区域的文字：
- 当前模板列表没有记录：还没有战术。
- 比赛历史没有留档：本场比赛尚未留存战术。
- 已有记录但搜索无匹配：没有找到匹配的战术，请调整搜索内容。

保留原 `!visible.length` 显示条件，不新增按钮，不改变布局、权限、搜索或历史快照接口。
