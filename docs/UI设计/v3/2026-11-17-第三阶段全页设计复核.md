# 第三阶段：全页设计差异修复与独立复核

## 范围与保护措施

在 `codex/ui-design-v3` 的隔离工作树实施。未修改用户原工作树、柏林来源数据、真实照片或原预览数据库；未配置外部密钥或调用付费 AI。保留原预览的临时域名校验配置，待用户结束预览后再恢复，避免打断现场。

## 本阶段修复

- 全局：统一字段标签颜色、字重及输入/选择底色；保留输入几何、边框可辨识度与触控尺寸。
- 首页：使用可复现的矢量生成脚本输出 144×144 快捷图标，不改变入口逻辑。
- 赛程、球员管理列表：修正图标、月份分隔、搜索与新增按钮、名单卡片、长姓名与号码换行。
- 比赛详情、编辑、名单、赛季阵容：时间移入设计指定区域，报名标题与分组层次、日期时间控件对齐、须知分隔、添加操作位置与禁用态。
- 球员详情、编辑、照片：字段和值层级、统计标题、紧凑位置标签、头像操作、照片说明与封面操作。
- 战术列表、创建、设置、板、编排、导入导出、图片导出：标题与工具排列、次级按钮描边、标签与间距、文件信息分组、输入内边距、文字居中。
- 微信认领、邀请、AI照片、强制改密、系统账号：信息层级、说明与按钮权重、密码占位说明、状态标签，保留原有权限与恢复路径。

## 独立审查发现并修复

1. 战术设置输入框垂直内边距挤压文字：改为水平内边距，保持控件高度。
2. 次级按钮覆盖禁用样式：限定正常态并补充禁用视觉。
3. 清除时间与位置标签禁用态不够明显：补充弱化样式。
4. 原生位置按钮默认占满整行：显式 `width:auto`，测试模拟原生 `button{width:100%}`，三档宽度断言三个标签同排且触控尺寸不小于 44px。
5. 名单“号码未设置”末字孤行：整段作为可整体换行的信息块。
6. 赛季日期说明误用蓝色信息块：恢复普通辅助文字。
7. 匿名比赛详情截图的参加标题未呈现成功色：核实是夹具漏了控制器已有的 `response` 字段；仅修正隔离夹具，未按标签文字修改业务判断。

## 已执行证据

- 完整小程序检查：821 项测试通过、0 失败、0 跳过；官方 WXML/WXSS 140 次渲染通过。这些结果不代表原生交互全部通过。
- 已逐页查看 32 页 375 宽正常态截图；7 页第二阶段及10页第三阶段另有320/430或320宽复核。最新局部修复需要以最新原生截图复核，不沿用旧图作为通过证据。
- 独立审查核对 WXML 事件、条件、数据绑定及禁用/加载约束；除首页资源路径外没有更改控制器和权限算法。
- 真实控制器与匿名临时 SQLite：管理员及球员登录、30条登录后路由加载、4个战术路由使用正确种子ID复核；日期选择取消与确认、保存后数据库日期/版本核对；球员参加→待定→请假后数据库仅一条报名记录；球员访问管理页被拒绝；退出后会话表为0。
- 原生鼠标实际点击账号输入框左右区域均可输入，密码可输入，验证文本已清空；不是仅通过程序设置value。
