## 范围与基线

- 设计依据：本目录中的《柏林花园FC_UI设计与开发规范_v3.pdf》、可交互 HTML 原型及 PNG 总览。
- 代码基线：`1f2505bd2f2bd7729475d73573639584c80ab3d4`；开发分支：`codex/ui-design-v3`。
- 本轮覆盖小程序 32 个原生页面与 5 个现有公共组件，不改 Web 端结构、后端、数据库、认证规则或部署配置。
- 使用品牌紫、冰蓝、浅紫底和白卡。素材是用户设计原型内嵌的生成品牌氛围图，不代表真实球场、球衣或球员；真实头像继续由既有数据提供。
- 默认保留原生导航；不复制设计浏览器状态栏、微信胶囊或屏幕固定高度。

## 验收标准

1. **视觉**：标题、正文、辅助信息层次明确；品牌横幅与业务内容分层；不以整屏图片替代控件。
2. **数据**：未知与零区分，报名不等于出场；历史快照与权限保持原口径；不填充示例球员、比赛或统计。
3. **操作**：原事件、字段、条件、禁用与对象标识保持；请求后才反馈成功；失败、冲突、待核对仍可恢复。
4. **组件**：选择器边框闭合，长值换行，取消不回写；弹框不被地图/画布盖住；原生输入光标不受排版修改影响。
5. **尺寸**：320/375/430 三档；长姓名、四位号码、无图/图片失败；安全区与键盘不能遮住唯一保存操作。
6. **真实测试**：模板渲染和静态检查不是微信操作验证；未实际执行的环节保持待验证。
