# 第十三阶段：系统账号与强制改密验证

## 13A：首次强制改密（原生已完成）

全新匿名隔离库，启动服务前对显式传入的临时数据库调用既有初始化导出函数，建立匿名系统管理员，强制改密标记为1。这是测试前提，不算UI创建系统管理员；未执行会默认访问正式库的脚本CLI。临时凭据只保存在本地受限文件/内存，不进入仓库或报告，原生密码框均掩码。

| 真实操作 | 核验结果 |
|---|---|
| 初始密码登录 | 实际进入首次修改密码页 |
| 新密码不足10位、两次不一致 | 页面阻止，改密PUT为0 |
| 当前密码错误 | 服务端403，未改密码 |
| 新密码等于初始密码 | 服务端400，未改密码 |
| 正确填写并修改 | 204，返回登录页 |
| 再用原密码登录 | 401，不能登录 |
| 新密码登录 | 200，正常业务首页 |
| 正常退出 | 登录页，活动会话0 |

成功改密后account_revision仅1→2，must_change_password变0，该用户所有旧会话均撤销；额外独立旧会话实际请求/auth/me返回401，不仅靠界面退出推断。其他球队、球员、比赛、相册和战术业务摘要不变。

## 收尾与范围

正常UI退出后会话0，隔离配置原字节恢复，只停止本次代理与后台；未改变真实账号或用户预览。产品源码无变化，不把本轮测试前提当新增功能。

普通管理员创建、启停、关联球员角色切换及系统账号权限入口继续下一批；未覆盖项不记通过。真实微信登录和外部平台能力仍未验证。
