# 第十七阶段S：编排草稿保护与删除撤销

日期：2026-11-18。开发分支 `codex/ui-design-v3`。本批没有修改业务源码。

## 原生操作

使用全新匿名库、隔离小程序和只读业务代理。代理允许GET与正常本机登录/退出，拒绝业务写请求；全过程没有发生被拒绝的业务写请求。

1. 进入已有两阶段、一条相邻曲线的战术编排页。实际输入未应用阶段标题，切换球员属性时出现确认；取消保留标题与当前页，确认才切换，回阶段编排后恢复原标题。
2. 删除阶段弹窗取消保留原两阶段；确认删除仅改草稿，剩原第二阶段并重编号为0，相邻曲线清除，保存计数1。点击撤销后完整模型（含曲线）恢复、保存计数0。
3. 再输入未应用标题，点击顶部返回显示未保存离开保护；取消保留输入，确认返回首页。重新进入后完整模型与最初一致。

全程使用真实控件点击和输入；运行时读取仅作断言，没有调用页面方法或setData伪造操作。只读代理没有把被阻止写入当作正常通过。

## 证据与数据核对

本地 `football-ui-v3-interaction/tactic-stage17s` 保存截图、before/deleted/undo/reopened模型、完整SQLite基线和请求日志。独立只读复核确认：

- 删除草稿为 delete-stage 0，原第二阶段正确保留，runs为空，参与者不变。
- undo与reopened完整model深相等，commands为空、changes为0。
- 23张业务表及表名集合与基线一致（排除会话及SQLite序列）；没有业务写入。
- 原生取消/确认顺序以实际UI记录为据，不能由数据库一致单独反推。

小程序完整1220项测试、140次官方模板虚拟渲染通过。正常退出后临时库会话0；配置恢复、s2关闭、临时进程停止及端口拒绝连接均已核验。正式数据和原工作区未改。

## 范围限制

本阶段验证编排页未应用标题、切换、离开保护和阶段删除撤销，不代表删除持久化、所有属性组合、系统强制杀进程或真机验证。多人多阶段动画、曲线联动与播放一致性继续下一阶段；不以本次通过宣称全部战术功能完成。
