# 网页账号权限与首次改密

## 入口及权限

- 系统管理员在左侧导航进入「账号权限」，只管理当前球队账号。
- 普通管理员与球员不能访问此页面。界面限制不替代服务端鉴权。
- 系统管理员记录只读；球员账号可授予管理员权限。带球员关联的管理员可撤权回球员，独立管理员只能停用或启用。
- 权限及启停操作需要确认，并携带账号版本。发生冲突或网络异常后先刷新核对，不自动重试写入。

## 临时密码

创建普通管理员时设置 10–200 位临时密码，首次登录必须更新。密码仅保留在当前输入框中，提交后清空，不写入日志或浏览器持久存储。

首次改密期间，无论直接打开哪个业务地址，都进入独立改密页；服务器只允许查询当前身份、修改密码和退出登录。修改成功清除旧会话并重新登录。普通修改密码继续遵守原有强度要求。

系统管理员初始化由独立本地工具执行。账号和初始密码不写入本文档、代码或测试。

## 不确定结果

创建请求超时、断网或服务端异常时，表单锁定，不重复提交。使用「核对创建结果」刷新账号列表：用户名存在仅表示账号已存在，不能据此断言上次密码成功设置；暂未找到也不能证明请求未执行。应先确认服务端最终结果。

## 验证边界

`app/tests/system-accounts-web.spec.ts` 使用匿名身份及模拟接口，覆盖直接访问强制改密、确认密码、权限入口、取消确认、版本提交、创建结果未知与迟到认证错误。它验证网页交互及请求形态，不替代服务端真实权限集成测试或人工视觉验收。

补充真实隔离联调：第七项测试在带所有权标记的临时 SQLite 数据库初始化匿名系统管理员，经真实浏览器完成首次改密、重新登录、创建普通管理员、普通管理员改密登录，并检查权限拒绝。前六项使用模拟接口，第七项使用真实接口和数据库。测试服务结束清理临时库，不访问项目默认库。七项均通过，尚不代表人工视觉验收或真实部署环境验证。
