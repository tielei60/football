# 战术文件选择与会话生命周期修复

## 已证问题和最小改动

匿名页面测试复现：旧账号刷新请求迟到返回 401 后会触发新页面登录导航；已选有效文件后，重新选定的文件读取失败仍保留旧集合，可能误导入旧文件。

- 刷新捕获请求前账号与页面可见代次；隐藏、重新进入、换账号后的旧结果不能改当前错误或导航。
- API 仅增加本地 `staleSession` 错误标记，不改错误状态、鉴权、会话清理或凭据。请求捕获代次是否失效在处理当前 401 清理之前判断；`ensureSession` 自身迟到成功转错误也标记。服务端返回的同名字段不被信任或复制。
- 当前账号真正 401/403 即使已经清空会话，仍显示失效错误；当前强制改密错误不误标旧请求。A→B→退出后旧 401 被导入页忽略。
- 系统文件选择取消保留原有效选择。确认选定新文件后立即清空旧集合、文件名、计数和成功摘要，再验证及读取；格式、读取或解析失败不得继续导入旧集合。
- 正常文件选择器触发 hide/show 不丢选择结果；选图回调独立按账号与选择代次门控，而不是误用页面可见代次。旧选择 success/fail/complete、换账号及卸载后回调不能污染新状态。换账号清除旧读取 busy，避免永久禁用。
- 导入幂等任务、未知结果守卫、导出格式及临时文件清理规则均未变更。没有修改服务、真实资料、素材、数据库或安全设置。
