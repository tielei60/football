# 阶段41：球员档案照片入口上下文

## 范围与设计核对

球员档案继续按照交付包 `08-player-detail-full.png`：紫色身份区、独立照片入口、比赛表现和报名统计。原图的紫色标签与数字不改成其他语义色。本次不修改 WXML、WXSS、页面结构或数据权限规则。

前次已查看交付原图；本阶段在独立云端代码副本上补充代码审查。Mac 当前离线，不能将云端测试称为本地微信开发者工具验证。

## 发现与修复

原照片入口只检查加载状态、错误和路由编号，没有绑定已成功加载的账号及展示球员。控制器用例复现：加载后原地切换账号，旧页面仍可发起照片导航；路由编号与展示球员不一致时也可导航。照片目标页本身仍有鉴权，这不是已证明的数据越权。

现在入口同时核对令牌、服务地址、用户、球队、路由球员和展示球员；加载前清空旧上下文，加载前后校验身份，迟到请求不得覆盖新刷新。凭据只存页面私有字段，不进入 `setData`。

独立复查发现初稿误把 `ensureSession()` 的公开返回值当完整私有会话。已修复为从 `getSession()` 捕获私有字段，并将测试桩严格按真实契约只返回 `{user, team}`。现有统计范围测试仅补齐缺失的会话桩，保留全部原断言；源码契约只精确反向投影本次改动，原始哈希未重置，另有篡改与重复片段检测。

## 验证与限制

- 新增7项控制器测试通过：正常入口、账号/球队/服务/令牌切换、球员不一致、隐藏卸载、刷新失败、迟到请求、忙碌及重试。
- 定向组合：24项通过，1项浏览器视觉检查因环境跳过。
- 后端临时数据库回归：235项通过；应用构建通过。
- 官方 WXML/WXSS 虚拟渲染：32页面、5组件、140次渲染通过，不代表设备交互或视觉验收。
- 全量测试：1321项中1294项通过、27项浏览器布局检查受云端环境限制，整套检查未全绿：官方 Chromium 下载文件无效；系统 Chromium 启动时 `socket() failed: Operation not permitted`。未关闭这些断言或把它们标成通过。
